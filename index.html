악취 시민제보

로그인 없이 참여 가능, 위치·시간은 제보 시 자동 전송

1) 위치 확인(참고용)

위치 미확인

제보 제출 시 자동으로 위치를 다시 수집한다. PC에서 위치가 부정확하면 스마트폰으로 제보를 권장한다.

2) 냄새 정보 입력

2
0 무취 5 매우 강함
강도 의미 · 0 무취 · 1 매우 약함(인지 어려움) · 2 약함(인지됨) · 3 보통(명확) · 4 강함(불쾌) · 5 매우 강함(참기 어려움)

설치(앱처럼 사용)

  1. 스마트폰에서 본 페이지 접속
  2. 브라우저 메뉴 → 홈 화면에 추가
  3. 이후 아이콘으로 앱처럼 실행
